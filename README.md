# ETL pour l'analyse des retards des Compagnies aeriennes Tunisair et Tunisair Express
### Outils utilisés

ETL -> Python: Polars (une librairie comme Pandas mais plus performante).

SGBD: SQLite.

Visualisation: Metabase conteneurisé avec Podman.


### Données
Base de Données: TUN_RETARDS

Table: tunisair_retards20
